# Descrição do sistema (rascunho: reescrever com as suas palavras)

Professores da educação básica pública lecionam para turmas com níveis de aprendizagem muito diferentes e têm pouco tempo para preparar atividades adequadas a cada perfil.
O nivela-ai é um sistema web em que o professor informa disciplina, série e tema e recebe a mesma atividade em quatro versões: reforço, padrão, avançada e adaptada, cada uma com gabarito.
Os usuários-alvo são professores da educação básica, que revisam, editam e salvam as atividades.
A IA atua como assistente: gera as questões e os gabaritos de cada nível a partir dos dados informados, e o professor tem sempre a palavra final.
Na Sprint 1, o frontend em Next.js funciona com dados mockados; a IA e a API entram na Sprint 2.
